# firmware

STM32F107 固件放在这里，由负责嵌入式和 AI 的同学来写。用 HAL，不要用课程里 STM32F103C8 的标准外设库。

硬件同学提供满量程、DT/SCK 接线和标定用的原始值。这些没到之前，先做串口的 `BOOT`，先不读传感器。顺序在 `docs/todo.md` 的 6.1 起。

6.1 工程是 `MDK-ARM/ScaleBoot.uvprojx`，Target 名 `ScaleBoot`，器件 `STM32F107VC`。串口沿用课程 UART 实验：USART1，PA9 发送，PA10 接收，115200 8N1。上电发送一行状态 `BOOT`，然后停在循环里。Keil 已编译通过。还没有下载到板子上。

施工说明是 `docs/firmware-handoff.docx`。里面有软件已经做完的部分、开发板之外还要准备的零件，以及固件可以跟着做的顺序。

课程电脑上已验证的 HAL 示例器件是 STM32F107VC。板子封装如果不是 VC，工程里改成实际型号。Keil 路径不要有中文。不要把点灯工程拷进这个目录。

HX711 的读数、去皮和比例校准可以参考现成驱动，许可证确认前不要把别人的源码拷进本仓库。
