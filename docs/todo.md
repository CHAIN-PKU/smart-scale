## 识别和单价

不在本地保存全部商品单价。

1. 摄像头拍照。
2. 多模态模型只回答这是什么。可选 MiniMax 或火山引擎，由 `VISION_PROVIDER` 切换。
3. 一个更小的纯文本模型根据名称查询单价和简介。它不看图片。
4. 融合层再用秤上的克数检查这个判断是否合理，并计算金额。
5. 本地 SQLite 只存每次称重、纠错和设备事件，方便以后复查。它不是商品总价表。

没有 key 时不访问网络。key 写在本机 `.env`，不要提交。样例在 `.env.example`。
