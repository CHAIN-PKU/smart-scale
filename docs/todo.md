## 识别和单价

不在本地保存全部商品单价。

1. 摄像头拍照。
2. 多模态模型只回答这是什么。可选 MiniMax 或火山引擎，由 `VISION_PROVIDER` 切换。
3. 一个更小的纯文本模型根据名称查询单价和简介。它不看图片。
4. 融合层再用秤上的克数检查这个判断是否合理，并计算金额。
5. 本地 SQLite 只存每次称重、纠错和设备事件，方便以后复查。它不是商品总价表。

没有 key 时不访问网络。key 写在本机 `.env`，不要提交。样例在 `.env.example`。

## 接下来

5.21 之后不再加新的「另一种不计价」。协议以 `docs/protocol.md` 为准，状态以 `docs/state-machine.md` 为准。固件按这两份实现，不用再设计一套。

每个新样本发一行 `weight`，行里的 `stable` 表示稳不稳。电脑只对稳定且状态合适的那一行计价。上电不要自动去皮。过载线是满量程的 90%，满量程没到手之前不写死一个大数。HX711 示例代码先别拷进仓库，等许可证确认。Keil 工程路径不要有中文。课程 HAL 示例的器件名是 STM32F107VC，以板子上的型号为准。
